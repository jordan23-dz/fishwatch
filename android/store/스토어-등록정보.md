## 자세한 설명 (4000자 이내)

```
FishWatch는 온라인에 올라오는 수산물 판매글을 수산자원관리법 시행령의 금어기(별표 1)와 포획 금지체장(별표 2) 기준으로 점검하는 도구입니다.

■ 이런 글을 찾아냅니다
· 금지체장보다 작은 크기를 적은 판매글 (예: 넙치 30cm, 전복 8cm)
· 어린 개체를 부르는 말 (총알오징어, 풀치, 고도리, 상사리, 뺀찌 등)
· 연중 포획이 금지된 대게 암컷(빵게), 국내산 명태
· 금어기 중에 "오늘 조업", "활어", "산지직송"을 내세운 판매글

■ 주요 기능
· 네이버 카페·블로그와 웹문서 검색에 노출된 스마트스토어, 당근, 쿠팡, 11번가, G마켓, 옥션 판매글 수집
· 매일 정한 시각에 자동 점검, 새 의심 판매글 알림
· 의심 판매글마다 근거 조항(별표·호)과 판정 이유 표시
· 확인 완료 / 제보함 / 오탐 표시로 검토 관리
· 판매글을 붙여넣어 바로 판독
· 어종 51종의 금어기·금지체장 기준표와 오늘의 금어기 어종

■ 사용 전 준비
네이버 클라우드 플랫폼의 NAVER API HUB에서 검색 API 키(무료)를 발급받아 설정에 입력합니다. 키 없이도 예시 데이터로 기능을 확인할 수 있습니다.

■ 알아 두세요
· 검색 결과의 제목·요약문만 읽는 1차 선별 도구입니다. 수입산·양식산·냉동 재고 여부는 원문과 증빙으로 확인해야 합니다.
· 시·도 조례나 해마다 고시되는 기간(고등어·꽃게 등)은 "확인 필요"로 표시합니다.
· 해양수산부, 해양경찰청, 네이버와 관계없는 개인 개발 도구이며, 판정은 법적 판단을 대신하지 않습니다.
· 위반이 의심되면 해양경찰 122 또는 관할 시·군·구 수산 담당 부서에 제보할 수 있습니다.

검색 결과 제공: NAVER 검색 API
```

## 데이터 보안 양식

| 질문 | 답 |
|---|---|
| 사용자 데이터를 수집하거나 공유하나요? | **아니요** |
| 이유 | API 키·설정·점검 결과는 기기에만 저장되고 개발자 서버로 전송되지 않음. 네이버 API 호출은 사용자가 요청한 기능 수행을 위한 전송이며, 검색어는 사용자 개인정보가 아님 |
| 전송 중 암호화 | 예 (HTTPS) |
| 데이터 삭제 요청 방법 | 앱 설정의 [저장된 점검 결과 모두 삭제] 또는 앱 삭제 |
