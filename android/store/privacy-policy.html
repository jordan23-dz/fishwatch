FishWatch 개인정보처리방침

시행일: 2026년 11월 10일

FishWatch(이하 "앱")는 [개발자 이름]이 개인적으로 개발한 도구로, 해양수산부·해양경찰청·네이버와 관계가 없습니다. 앱은 이용자의 개인정보를 수집하지 않습니다.

1. 수집하는 정보

앱은 이름, 연락처, 위치, 기기 식별자 등 개인정보를 수집하지 않으며, 개발자에게 어떤 정보도 전송하지 않습니다. 광고와 분석 도구도 포함하지 않습니다.

2. 기기에 저장되는 정보

이용자가 입력한 네이버 API 키(Client ID·Secret), 앱 설정, 점검 결과(판매글 제목·요약·링크, 검토 표시)는 이용자의 기기 안에만 저장됩니다. 앱 설정의 [저장된 점검 결과 모두 삭제] 또는 앱 삭제로 지울 수 있습니다.

3. 외부로 전송되는 정보

점검을 실행하면 검색어와 이용자의 API 키가 네이버 검색 API(네이버 클라우드 플랫폼 NAVER API HUB)로 HTTPS 암호화되어 전송됩니다. 이 전송은 네이버의 개인정보처리방침과 이용약관을 따릅니다. 판매글 링크를 누르면 기기의 브라우저로 해당 사이트가 열립니다.

4. 권한

  • 인터넷: 네이버 검색 API 호출
  • 알림(선택): 자동 점검에서 새 의심 판매글을 찾았을 때 알림

5. 아동의 개인정보

앱은 아동을 대상으로 하지 않으며 아동의 개인정보를 수집하지 않습니다.
