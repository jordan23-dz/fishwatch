자동 점검

인터넷에 연결돼 있을 때 정한 시각 무렵에 돌고, 절전 상태에 따라 조금 늦어질 수 있습니다.

키 발급 방법

  1. 네이버 클라우드 플랫폼에 로그인하고 콘솔에서 NAVER API HUB를 이용 신청합니다.
  2. Application → [Application 등록]을 누릅니다. 따로 앱이나 웹사이트를 만들 필요는 없습니다.
  3. 카페글 검색, 블로그 검색, 웹문서 검색을 체크합니다.
  4. 이름을 영문·숫자·하이픈 20자 이내로 입력합니다(예: fishwatch).
  5. 목록의 [인증 정보]에서 Client ID와 Client Secret을 복사해 위 칸에 붙여넣고 저장합니다.

계정의 IAM 키(Access Key)는 쓸 수 없습니다. 키는 이 휴대폰 안에만 저장되고 화면에 다시 표시되지 않습니다.
