# FishWatch — 수산물 판매글 자동 점검

온라인 판매글을 주기적으로 모아 수산자원관리법 시행령의 **금어기(별표 1)** 와 **포획 금지체장(별표 2)** 으로 판독하고, 위반 의심 글을 보고서로 정리합니다. 판정 로직은 웹 도구 「금어기·체장 판독기」와 같습니다.

## 무엇을 어떻게 모으나

| 대상 | 수집 경로 |
|---|---|
| 네이버 카페 | NAVER API HUB 카페글 검색 |
| 네이버 블로그 | NAVER API HUB 블로그 검색 |
| 네이버 쇼핑(스마트스토어), 당근, 쿠팡, 11번가, G마켓, 옥션 | NAVER API HUB 웹문서 검색에 노출된 문서만 |

- 네이버 **쇼핑 검색 API는 2026-07-31에 대체 없이 종료**되어, 스마트스토어 글도 웹문서 검색으로 찾습니다.
- 당근·쿠팡·11번가·G마켓·옥션에는 **직접 접속하지 않습니다.** 검색엔진이 이미 공개한 제목·요약문만 사용하므로 사이트 약관상 자동 수집 금지 조항과 충돌하지 않습니다. 그 대신 검색엔진에 색인되지 않은 글은 놓칩니다.
- **판매·거래·경매 글만** 모읍니다. 카페·블로그 글은 '판매·팝니다·거래·직거래·경매·위판·낙찰·가격(원)' 같은 표현이 있어야 하고, 제목이 요리·맛집·뉴스·단속·조황 글이면 뺍니다. 쇼핑몰·중고거래 사이트 글은 그 자체로 판매글로 봅니다.
- 불법 수산물 점검과 무관한 글은 뺍니다(설정에서 항목별로 끄고 켤 수 있음): **수산물이 아닌 상품**(액막이 명태 같은 장식품, 낚싯대·채비, 사료·미끼 등), **가공품**(건조·훈제·젓갈·굴비·황태·어묵·양념 등, 냉동·손질은 포함), **수입산**, **양식**.
- 판독은 **제목 + 검색 요약문**만으로 합니다. 본문 전체·사진은 보지 않으므로 1차 선별용입니다.

검색어는 매 실행마다 자동으로 구성됩니다.
1. 상시 감시어: 총알오징어, 풀치, 고도리, 빵게, 국산 명태 등 금지체장 미만 개체를 가리키는 은어
2. 실행일 기준 금어기인 어종 이름 + "판매"
3. `config.toml`의 `extra_queries`
4. 위 검색어 × 사이트명(당근, 쿠팡, 11번가 …)으로 웹문서 검색

## 앱 실행 (추천)

Python 3.11 이상을 설치한 뒤(설치 시 "Add python.exe to PATH" 체크) 폴더 안의 실행 파일을 더블클릭합니다.

- Windows: `FishWatch.bat`
- macOS: `FishWatch.command` (처음엔 우클릭 → 열기)

브라우저에 앱 화면(http://127.0.0.1:8765)이 열립니다. 이 화면은 내 컴퓨터에서만 열리고, 검은 창을 닫으면 앱이 꺼집니다.

| 화면 | 하는 일 |
|---|---|
| 점검 현황 | 지금 점검 / 예시 데이터로 시험, 진행 상황, 의심 판매글 목록(사이트·등급·검토 상태 필터), 글마다 "확인 완료·제보함·오탐" 표시 |
| 직접 판독 | 판매글을 붙여넣어 바로 판독 |
| 기준표 | 어종별 금어기·금지체장과 오늘 상태 |
| 설정 | API 키, 수집 대상, 호출 상한, 추가 검색어, 매일 자동 점검 시각 |

처음에는 키 없이 **예시 데이터로 시험**을 눌러 보세요.

## API 키 발급 (NAVER API HUB)

실제 앱이나 웹사이트는 필요 없습니다. 콘솔에서 쓸 API를 고르고 이름만 붙이면 됩니다.

1. 네이버 클라우드 플랫폼(ncloud.com) 로그인 → 콘솔에서 **NAVER API HUB** 이용 신청
2. **Application → [Application 등록]** → 카페글 검색, 블로그 검색, 웹문서 검색 체크
3. 이름 입력(영문·숫자·하이픈 20자 이내, 예: fishwatch) → 완료
4. 목록의 **[인증 정보]**에서 Client ID / Client Secret 복사 → 앱 **설정** 화면에 붙여넣고 저장

계정 IAM 키(Access Key)는 쓸 수 없습니다(401 오류). 2026-07-30 이전 개발자센터 키가 있다면 설정에서 "기존 개발자센터 키"를 고르면 2027-06-30까지 쓸 수 있습니다.

## 앱을 켜 두지 않고 자동 실행

앱의 자동 점검은 앱이 켜져 있을 때만 돕니다. 컴퓨터만 켜져 있으면 돌게 하려면:

- Windows: `schedule_windows.bat` 실행 → 매일 08:47 등록
- macOS·Linux: `sh schedule_unix.sh`

이 방식은 화면 없이 `run.py`를 실행하고, 결과는 다음에 앱을 열면 점검 현황에 함께 보입니다. 명령줄로 직접 돌리려면 `python run.py` (예시: `python run.py --mock`).

한 번 점검에 약 230회 API를 호출합니다(검색 API 한도 하루 25,000회).

## 결과물

- 앱의 점검 현황 화면 — 누적된 의심 글과 검토 상태
- `reports/latest.html` — 마지막 점검의 위반 의심·확인 필요 글. 사이트·등급·신규 필터 제공
- `reports/report-날짜.csv` — 판독한 모든 글(엑셀에서 바로 열림)
- `fishwatch.db` — SQLite. 같은 글은 한 번만 저장되고, 처음 발견된 날짜가 남아 **신규** 글을 구분합니다.

## 한계

- 요약문이 잘려 크기 표기가 빠진 글이 많습니다. 의심 글은 링크를 열어 원문을 확인하세요.
- 카페글 검색 결과에는 작성일이 없어 **실행일**을 게시일로 보고 판독합니다(블로그는 작성일 사용).
- 고등어·꽃게 금어기는 해마다 해양수산부 고시로 정해지므로 "확인 필요"까지만 판정합니다.
- 시·도 조례로 강화·변경된 기준, 비어업인 별도 기준은 반영하지 않습니다.
- 규칙 데이터는 `rules.json`에 있습니다. 시행령이 개정되면 이 파일만 고치면 됩니다.

판정 근거: 수산자원관리법 시행령 별표 1·2(2024. 6. 4. 개정), 2026. 6. 24. 해양수산부 TAC 어선 금어기·금지체장 유예 조치(2027. 6. 30.까지).


## 다른 사람에게 나눠 주기 (FishWatch.exe)

받는 사람은 Python 없이 **FishWatch.exe 하나**만 더블클릭하면 됩니다. API 키는 각자 설정 화면에서 넣습니다.

### exe 만들기 — 방법 A: 내 PC에서 (Windows)
1. 이 폴더의 `build_exe.bat`을 더블클릭합니다(Python 3.11 이상 필요, 처음엔 1~3분).
2. 끝나면 `dist\FishWatch.exe`가 열립니다. 이 파일 하나만 보내면 됩니다.

### exe 만들기 — 방법 B: GitHub가 자동으로 (권장, 다운로드 링크로 배포)
1. GitHub에 새 저장소를 만들고 이 폴더를 올립니다(`config.toml`, `fishwatch.db`는 .gitignore로 제외됨).
2. **Actions** 탭 → "Build FishWatch.exe" → **Run workflow**. 몇 분 뒤 실행 결과의 Artifacts에서 exe를 받습니다.
3. 정식 배포: **Releases → Draft a new release**에서 태그(`v1.0.0`)를 새로 만들고 **Publish release**를 누르면, 몇 분 뒤 그 배포판에 FishWatch.exe가 자동으로 붙습니다.
4. 나눠 줄 주소: `https://github.com/<아이디>/<저장소>/releases/latest/download/FishWatch.exe` (항상 최신판을 받음)
5. 고칠 때마다 `paths.py`의 `VERSION`과 `version_info.txt`의 버전을 올리고 새 배포판(v1.0.1 등)을 만드세요.

### 받는 사람이 알아야 할 것
- 처음 실행 때 Windows가 "Windows의 PC 보호" 경고를 띄우면 **[추가 정보] → [실행]**을 누릅니다(서명되지 않은 프로그램이라 뜨는 경고). 없애려면 코드 서명 인증서(유료)가 필요합니다.
- 검은 창이 함께 뜹니다. 이 창을 닫으면 앱이 꺼집니다.
- 설정·점검 기록·보고서는 `%APPDATA%\FishWatch`에 저장됩니다(설정 → 앱 정보 → [데이터 폴더 열기]). exe를 새 버전으로 바꿔도 그대로 유지됩니다.
- USB 등에 넣고 다니려면 exe 옆에 `portable.txt`라는 빈 파일을 두세요. 그러면 데이터를 exe 폴더에 저장합니다.
- 앱을 꺼 두어도 매일 점검하려면 설정 → 자동 점검 → **[Windows 작업 스케줄러에 등록]**을 누릅니다(`FishWatch.exe --run-once`가 등록됨).
- 이전 폴더판을 쓰던 사람은 exe 옆에 기존 `config.toml`, `fishwatch.db`를 두고 처음 실행하면 자동으로 옮겨집니다.
